Detailed Description

Exception thrown by colvarmodule::error_static() when no module pointer is available.

Colvars normally reports errors through return codes. This exception is the one exception to that rule: it lets lightweight objects without a module pointer (vectors, colvarvalue...) abort the current operation. It is caught at the module's entry points (calc(), parse_config(), setup_input(), colvarscript::run()), which forward it to colvarmodule::error() and thus to the engine's proxy: the engine then decides whether the error is fatal (MD engines) or not (VMD).
